# Biomedical publication context

When publication work is requested, read the canonical Biomedical Publication Suite SKILL.md if available and load only its relevant references. Work through evidence and editorial judgment; scripts and ledgers are optional.

Write for an outside scientific reader: final question, methods, findings and interpretation. Omit irrelevant discarded analyses and drafting history; state findings directly and consolidate detailed limitations. Preserve the qualifications needed for truth and actual disclosure obligations without defensive sentence-by-sentence hedging. Never invent prospective planning, citations, results or author declarations. Distinguish source identity from claim support and inspect evidence for material claims. Return the requested artifact first and only necessary author-facing concerns separately.
