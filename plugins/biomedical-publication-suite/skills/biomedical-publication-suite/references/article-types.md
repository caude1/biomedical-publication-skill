# Article and artifact types

Select structure by the requested output and current venue. IMRAD is useful for original research; it is not universal. A separate Conclusion or Limitations section is optional unless the venue requires it. Use [reporting-and-journal-routing.md](reporting-and-journal-routing.md) when design-specific coverage matters.

| Output | Structure and scientific contract |
|---|---|
| Original research | Question, reproducible methods, complete key results, interpretation and limitations. Preserve analysis populations and primary/secondary/exploratory roles. |
| Brief report / research letter | One focused question, compact methods/results and proportionate interpretation. Confirm whether an abstract is permitted/required. Compression cannot remove material uncertainty or harms. |
| Case report / case series | Clinically necessary chronology, assessment, intervention and outcome. Verify actual publication consent and privacy; never invent a quotation or consent statement. A case does not establish general treatment efficacy. |
| Systematic review / meta-analysis | Prespecified eligibility, reproducible search, screening, extraction, appraisal and synthesis. Load [review-methods.md](review-methods.md); aggregate published data are not a new patient cohort. |
| Scoping review | Map evidence, concepts and gaps using explicit search/selection methods. PRISMA-ScR reporting; appraisal depends on question/method. Avoid unsupported treatment recommendations. |
| Narrative review | Define scope and organizing argument, explain selection to the extent available, and synthesize agreements/conflicts. Do not claim exhaustive/systematic coverage without actual methods. |
| Diagnostic accuracy | State the target condition, index test, reference standard, thresholds, and which participants received both tests. A comparison with an imperfect comparator may only establish agreement. |
| Prediction model | Name the intended use, prediction time, outcome horizon, model version and population used for evaluation. Separate apparent performance from internal and external evaluation. To claim that using the model benefits patients, locate a study of its clinical impact. |
| Translational / preclinical | State model system, experimental unit, replication and measured mechanism. Biological plausibility is distinct from demonstrated human efficacy. |
| Protocol / statistical analysis plan (SAP) | Identify document date, version, stage and any amendments. Use planned language for procedures still to come and past tense for completed steps, such as registration. For a retrospective plan, state what was known when it was written. |
| Methods paper | Define the problem, method and comparison. Distinguish a worked illustration or simulation from independent empirical evaluation, and tie claims about performance to the designs and settings actually tested. |
| Qualitative | Preserve analytic approach, context, researcher positioning, sampling rationale and authentic quotations. Themes are not prevalence estimates. |
| Implementation / quality improvement / economic evaluation | Distinguish implementation, clinical and resource outcomes; retain context, assumptions and sensitivity analyses. Before-after change alone does not establish treatment causality. |
| Guideline / consensus | Separate evidence certainty, recommendation strength, values, feasibility and panel process. Do not invent votes, consensus or endorsement. |
| Editorial / correspondence / commentary | Argument-led structure with opinion and inference distinguishable from verified facts. No forced IMRAD. |
| Grant / project narrative | Problem, gap, aims, approach, feasibility, dependencies and defensible expected contribution. Future work/preliminary findings cannot become completed validation or guaranteed outcomes. |
| Title / abstract / highlights | Derive from verified final manuscript; preserve scope, design, endpoint role and uncertainty under length constraints. No stronger claim than the body supports. |
| Caption / legend / table text / graphical summary | Self-contained description tied to actual display/source data. Identify units, n, uncertainty and comparisons where relevant; conceptual illustration is distinct from empirical evidence. |
| Cover letter / reviewer response | Accurate account of actual work, changes and venue fit. Never invent exclusivity, approvals, author agreement or completed analyses. |

Use [section-and-artifact-guides.md](section-and-artifact-guides.md) for drafting and [revision-response-and-submission.md](revision-response-and-submission.md) for reviewer/submission work.
